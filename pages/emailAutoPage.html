How It Works
📧 Auto Receipt Email
  • Triggers when admin adds a contribution
  • Sent to that member's email only
  • Includes receipt number, amount, date
  • Skipped if daily email quota is full
📅 Monthly Report Email
  • Runs on last day of the month (Apps Script trigger)
  • Contributed → receives their payment summary
  • Not contributed → receives a reminder email
  • Each member gets only their own data
🎂 Birthday Email
  • Runs daily at 8 AM via Apps Script trigger
  • Sent only to member whose birthday is today
  • Household-themed email in Hindi + English
  • Skipped if daily email quota is full
📋 Admin Monthly Summary
  • Runs on last day of month (separate trigger)
  • Sent to every active admin, not members
  • Who paid + who hasn't, PDF attached
  • Multiple entries per member → one total
Monthly report requires a Time-based trigger set up in Apps Script. Go to Apps Script → Triggers → Add trigger → sendMonthlyEndReports → Month timer → End of month.

Birthday email requires a separate daily trigger: Apps Script → Triggers → Add trigger → sendBirthdayEmails → Time-based → Day timer → 8 AM – 9 AM.

Admin Monthly Summary requires its own trigger: Apps Script → Triggers → Add trigger → sendAdminMonthlySummary → Month timer → day of your choice.
